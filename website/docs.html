ใจปู

UNIT-01 · QUEUE / MOD

ระบบคิวเข้าห้อง จองคิวล่วงหน้า แยกห้องประชุมกลุ่มย่อยอัตโนมัติ และเครื่องมือ moderation ครบชุดสำหรับดูแลเซิร์ฟเวอร์

/queue — ระบบคิว
/queue join
เข้าคิว ระบบจะบอกตำแหน่งคิวของคุณทันที
/queue book
date: 2026-08-20time: 14:30
จองคิวล่วงหน้า ระบบจะ DM แจ้งเตือนก่อนถึงเวลา 10 นาที และเพิ่มเข้าคิวให้อัตโนมัติ
⚠ ต้องเปิดรับ DM จากสมาชิกเซิร์ฟเวอร์ไว้ ไม่งั้นจะไม่ได้รับการแจ้งเตือน
/queue board แอดมิน
โพสต์กระดานคิวสด รวมปุ่มเข้า/ออกคิว + เรียก/จบ/รีเฟรช ในข้อความเดียว อัปเดตแบบเรียลไทม์
/breakout — ห้องประชุมกลุ่มย่อย
/breakout start แอดมิน
source: ห้องหลักrooms: 3
สุ่มแบ่งคนในห้องหลักออกเป็นห้องย่อยตามจำนวนที่ระบุ (2-10 ห้อง) สร้างห้องและย้ายคนให้อัตโนมัติ
/breakout setowner แอดมิน
member: @ชื่อroom: 1
กำหนดหัวหน้าห้องย่อย — จะได้สิทธิ์พูดคืนในห้องใหญ่อัตโนมัติตอน recall
/breakout setspeakers แอดมิน
channel: ห้องหลักrole: @วิทยากร
ตั้งค่าห้อง: เฉพาะบทบาทที่ระบุพูดได้ คนอื่นเข้าฟังอย่างเดียว
/breakout recall แอดมิน
ดึงทุกคนกลับห้องหลัก ลบห้องย่อยทิ้งอัตโนมัติ
EXAMPLE // เริ่มกิจกรรมกลุ่มย่อยแบบเต็ม
/breakout setspeakers channel:ห้องประชุมใหญ่ role:@วิทยากร /breakout start source:ห้องประชุมใหญ่ rooms:4 /breakout setowner member:@สมชาย room:1 /breakout recall
/mod, /automod, /welcome — Moderation
/mod kick, ban, timeout แอดมิน
เตะ/แบน/timeout สมาชิก พร้อมระบุเหตุผล
/automod toggle, addword, removeword แอดมิน
เปิด/ปิดระบบกรองคำอัตโนมัติ และจัดการรายการคำต้องห้าม
/welcome channel, message แอดมิน
ตั้งช่องและข้อความต้อนรับสมาชิกใหม่ — ตั้งได้ผ่าน dashboard ด้วย

ยาม

UNIT-02 · SURVEILLANCE

ติดตามว่าใครเข้าห้องเสียงไหน อยู่นานเท่าไหร่ นับจำนวนคนออนไลน์แบบเรียลไทม์ และส่งออกข้อมูลเป็นรายงาน

/track — จัดการห้องที่ติดตาม
/track add แอดมิน
channel: ห้องเสียง
เริ่มติดตามห้องเสียง — ต้องทำก่อนถึงจะใช้คำสั่งอื่นในห้องนั้นได้
/voice — ดูข้อมูลและสถิติ
/voice now
channel: ห้องเสียง
ดูว่าใครอยู่ในห้องตอนนี้ + อยู่มานานเท่าไหร่ + จำนวนคนออนไลน์
/voice stats
channel: ห้องเสียงdays: 7
สรุปเวลารวมของแต่ละคนในห้อง เลือกช่วงวันได้ (0 = ทั้งหมด)
/voice export
channel: ห้องเสียงdays: 30
ส่งออกข้อมูลเป็นไฟล์ CSV เปิดด้วย Excel ได้ทันที (รองรับภาษาไทย)
/voice graph
channel: ห้องเสียงdays: 14
ดูกราฟกิจกรรม (นาทีรวมต่อวัน) เป็นรูปภาพ
EXAMPLE // เริ่มติดตามและดูสถิติ
/track add channel:ห้องประชุมทีม /voice now channel:ห้องประชุมทีม /voice stats channel:ห้องประชุมทีม days:7 /voice export channel:ห้องประชุมทีม days:30
ระบบแนะนำตัวสมาชิก / จัดปาร์ตี้
/setup-introduction, /setup-playerboard แอดมิน
ตั้งค่ากระดานแนะนำตัว/รายชื่อสมาชิกแบบรูปภาพในห้องที่เลือก — สมาชิกใช้ /my-profile และ /edit-profile จัดการโปรไฟล์ตัวเอง
/party upload, /party generate แอดมิน
แนบรูปตารางปาร์ตี้ (SUN/MOON/DARK/FLASH) ให้บอทจัดโพยตามรูป หรือสร้างโพยอัตโนมัติจากรายชื่อผู้เล่นถ้าไม่มีรูป

Voice Relay

UNIT-03 · LIVE RELAY

ถ่ายทอดเสียงสดจากห้องบัญชาการ ไปยังห้องย่อยหลายห้องพร้อมกันแบบเรียลไทม์ — ควบคุมผ่านคำสั่งของบอท "หัวหน้า" เท่านั้น (บอทลูกน้องไม่มีคำสั่งของตัวเอง)

ข้อจำกัดสำคัญ: ห้องหลักควรเป็น Stage Channel ไม่ใช่ Voice Channel ธรรมดา เพราะ Discord บังคับเข้ารหัสเสียงแบบ E2EE (DAVE) กับ Voice Channel ทำให้บอทฟังเสียงไม่ได้ — Stage Channel ได้รับการยกเว้น
คำสั่งพื้นฐาน — เริ่มใช้งานด้วยมือ
/relay start แอดมิน
source: ห้องบัญชาการ
เริ่มฟังเสียงจากห้องหลัก (ยังไม่กระจายไปไหนจนกว่าจะเพิ่มปลายทาง)
/relay addtarget แอดมิน
channel: ห้องย่อย
เพิ่มห้องย่อยที่จะกระจายเสียงไป ใช้บอทลูกน้องตัวถัดไปที่ว่าง (รองรับสูงสุด 15 ห้องพร้อมกันในแพ็ก PRO)
/relay status ทุกคน
เช็คสถานะปัจจุบัน — ห้องไหนกำลังถ่ายทอดอยู่ ใช้บอทลูกน้องตัวที่เท่าไหร่
ผูกอัตโนมัติ — ไม่ต้องพิมพ์คำสั่งซ้ำทุกครั้ง
/relay bindlistener แอดมิน
channel: ห้องบัญชาการ
ผูกบอทฟังกับห้องหลัก — มีคนแรกเข้าห้องนี้ บอทเข้าอัตโนมัติ / ห้องว่าง บอทออกอัตโนมัติ
/relay bindspeakers แอดมิน
ผูกบอทลูกน้องสูงสุด 5 ตัวพร้อมกันในคำสั่งเดียว (เลือกตัวว่างให้อัตโนมัติ) — หรือใช้ /relay bindspeaker ระบุหมายเลขเอง
/relay unbind แอดมิน
ยกเลิกการผูกอัตโนมัติทั้งหมด (ยังใช้คำสั่ง manual ได้ปกติ)
EXAMPLE // ตั้งค่าครั้งเดียว ใช้ตลอดไป (แนะนำ)
/relay bindlistener channel:ห้องบัญชาการ /relay bindspeaker index:1 channel:ห้องลูกทีม1 /relay bindspeaker index:2 channel:ห้องลูกทีม2 /relay bindspeaker index:3 channel:ห้องลูกทีม3
จากนั้นไม่ต้องพิมพ์คำสั่งอะไรอีกเลย แค่เข้าห้องตามปกติ บอทจะตามเข้า-ออกให้เอง
หมายเหตุ: ค่าที่ผูกไว้เก็บในหน่วยความจำเท่านั้น หากบอทรีสตาร์ท ต้องตั้งค่าผูกใหม่อีกครั้ง
