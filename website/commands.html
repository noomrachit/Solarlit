ใจปู

UNIT-01 · QUEUE / MOD

ระบบคิว, breakout rooms, moderation, automod, welcome, custom commands, reaction roles และตั้งค่าบอท

/queue — ระบบคิว
คำสั่งคำอธิบายสิทธิ์
/queue joinเข้าคิวทุกคน
/queue leaveออกจากคิวทุกคน
/queue listดูรายการคิวทุกคน
/queue bookจองคิวล่วงหน้า (ระบุวันและเวลาไทย)ทุกคน
/queue unbookยกเลิกการจองคิวล่วงหน้าของตัวเองทุกคน
/queue bookingsดูรายการจองคิวล่วงหน้าที่รอดำเนินการแอดมิน
/queue callเรียกคิว (ไม่ระบุ user = เรียกคิวถัดไป / ระบุ user = เรียกจากกระดานคิวที่ถูกข้าม)แอดมิน
/queue skippedดูรายชื่อคนที่ถูกข้ามคิวแอดมิน
/queue requeueนำคนที่ถูกข้ามกลับเข้าคิวหลัก (ต่อท้ายคิว)แอดมิน
/queue clearล้างคิวทั้งหมด (ไม่ลบกระดาน)แอดมิน
/queue refreshรีเฟรชกระดานคิวทั้งหมดในเซิร์ฟเวอร์นี้แอดมิน
/queue boardโพสต์กระดานคิวสด (ปุ่มเข้า/ออก/เรียก/จบ/รีเฟรชในที่เดียว)แอดมิน
/breakout — แยกห้องเสียงเป็นห้องย่อย
คำสั่งคำอธิบายสิทธิ์
/breakout startแยกคนในห้องเสียงออกเป็นห้องย่อยหลายห้องอัตโนมัติแอดมิน
/breakout recallดึงทุกคนกลับห้องหลัก และลบห้องย่อยทิ้งแอดมิน
/breakout moveย้ายสมาชิกคนใดคนหนึ่งไปห้องย่อยที่ระบุแอดมิน
/breakout setownerกำหนดหัวหน้าห้องย่อย (ได้สิทธิ์พูดกลับห้องใหญ่ตอน recall)แอดมิน
/breakout setspeakersตั้งค่าห้อง: เฉพาะบทบาทที่ระบุพูดได้ คนอื่นฟังอย่างเดียวแอดมิน
/breakout unsetspeakersยกเลิกการจำกัดสิทธิ์พูด คืนค่า @everyone ปกติแอดมิน

คำสั่งคำอธิบายสิทธิ์

/automod toggleเปิด/ปิด automodแอดมิน

คำสั่งคำอธิบายสิทธิ์

UNIT-03 · LIVE RELAY

ควบคุมผ่านคำสั่งของบอท "หัวหน้า" เท่านั้น (บอท "ลูกน้อง" ไม่มีคำสั่งของตัวเอง) — ทุกคำสั่งขึ้นต้นด้วย /relay

/relay
คำสั่งคำอธิบายสิทธิ์
/relay startเริ่มฟังเสียงจากห้องหลัก (ยังไม่กระจายจนกว่าจะ addtarget)แอดมิน
/relay addtargetเพิ่มห้องย่อยที่จะกระจายเสียงไป (ใช้บอทพูดตัวถัดไปที่ว่าง)แอดมิน
/relay removetargetเลิกกระจายเสียงไปห้องที่ระบุแอดมิน
/relay stopหยุดถ่ายทอดเสียงทั้งหมด (ทุกห้องของหัวหน้าตัวนี้)แอดมิน
/relay clearroleยกเลิกการกรองบทบาท กลับไปกระจายเสียงทุกคนในห้องหลักแอดมิน
/relay bindlistenerผูกบอทฟังให้เข้า/ออกห้องหลักอัตโนมัติตามความเคลื่อนไหวแอดมิน
/relay bindspeaker(s)ผูกบอทพูดตัวที่ระบุ (หรือหลายตัวพร้อมกันสูงสุด 5) ให้เข้า/ออกห้องย่อยอัตโนมัติแอดมิน
/relay unbindยกเลิกการผูกอัตโนมัติทั้งหมดของหัวหน้าตัวนี้แอดมิน
/relay statusเช็คสถานะการถ่ายทอดเสียงของหัวหน้าตัวนี้ตอนนี้ทุกคน
